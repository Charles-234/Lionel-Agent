A governed, general-purpose AI agent.

pip install lionel-agent && lionel init

Local install · no hosted control plane

Capabilities

Built to be audited, not trusted.

Governance

Every request is normalized, role-scoped, planned, and authorized before a tool can run. Decisions and their outcomes are appended to an audit ledger you can replay.

Multi-provider routing

Tasks are ordered across six providers, from hosted endpoints to a local model, per task type. A failed candidate falls through to the next one before the request is surfaced.

Local-first memory

Session, working, and persistent memory live in local stores that stay inspectable. Nothing leaves the machine except through a tool call that policy already allowed.

Modality support

Text, images, documents, audio, voice, and video are ingested with their metadata intact. Each modality is routed only to a provider that declares support for it.
